## 📖 О проекте
Данный проект представляет собой веб-приложение на базе Django, предназначенное для симуляции, отслеживания и аналитики ключевых экономических показателей. Система позволяет вводить исходные данные, запускать сценарии моделирования и наглядно визуализировать результаты.

## 🚀 Основной функционал (Модули)
Проект разделен на три ключевых приложения:
* 💸 **`transactions`** — модуль для учета, ввода и валидации финансовых транзакций и макроэкономических показателей.
* ⚙️ **`simulation`** — ядро системы, отвечающее за математические модели и проведение симуляций экономических сценариев.
* 📈 **`analytics`** — модуль обработки данных, построения графиков, трендов и формирования аналитических отчетов.
